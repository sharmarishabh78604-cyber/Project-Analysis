# FedEx Logistics Performance Analysis

## Project Overview

This project focuses on analyzing FedEx logistics and supply chain delivery performance using Exploratory Data Analysis (EDA) techniques in Python.

The project aims to identify operational inefficiencies affecting delivery timelines and freight costs and provide data-driven business recommendations to improve logistics performance and customer satisfaction.

---

# Business Problem Statement

FedEx logistics operations handle large volumes of shipments across different countries and transportation modes.

However, logistics operations often face challenges such as:
- delayed deliveries
- high freight costs
- inefficient shipment planning
- vendor-related issues
- regional transportation bottlenecks

The objective of this project is to:
- analyze shipment and delivery performance
- identify factors causing delivery delays
- evaluate freight cost patterns
- analyze vendor efficiency
- generate recommendations for improving logistics efficiency

# Key Business Insights

## Shipment Mode Insights
- Air shipment provides faster delivery but increases freight cost.
- Some shipment methods experience significantly higher delays.

## Vendor Insights
- Certain vendors consistently contribute to delayed deliveries.
- Vendor monitoring systems can improve operational reliability.

## Cost Insights
- Freight cost increases with shipment weight.
- Heavy shipments significantly impact transportation expenses.

## Regional Insights
- Certain countries consistently experience delivery delays due to operational and logistics challenges.

---

# Statistical Analysis

Correlation analysis was performed to identify relationships between important numerical variables.

Major findings:
- Positive correlation between shipment weight and freight cost.
- Delivery duration is related to delivery delays.
- Freight cost variability indicates presence of high-cost shipments.

---

# Recommendations

Based on the analysis, the following recommendations were proposed:

- Use air shipment only for urgent deliveries.
- Implement vendor performance monitoring systems.
- Consolidate heavy shipments to reduce freight cost.
- Improve warehouse and route planning.
- Focus on countries with repeated delivery delays.
- Improve shipment planning for operational efficiency.
