# FedEx Logistics Performance Analysis

## Project Objective
This project analyzes FedEx logistics delivery performance using Exploratory Data Analysis (EDA) techniques in Python.

The main objectives are:
- Improve delivery timelines
- Reduce freight costs
- Analyze shipment performance
- Identify vendor inefficiencies
- Generate business recommendations

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## Dataset Description
The dataset contains FedEx logistics delivery records including:
- Shipment mode
- Freight cost
- Vendor details
- Shipment weight
- Delivery schedules
- Actual delivery timelines
- Country-level shipment information

---

## Key Analysis Performed
- Missing value analysis
- Outlier detection
- Feature engineering
- Shipment mode analysis
- Vendor performance analysis
- Country-wise delay analysis
- Correlation analysis
- KPI analysis

---

## Business Insights
- Air shipment is faster but expensive
- Heavy shipments increase freight cost
- Certain vendors contribute to delivery delays
- Some regions experience repeated logistics delays

---

## Conclusion
The project identifies operational inefficiencies affecting FedEx logistics performance and provides recommendations for improving delivery efficiency and reducing transportation costs.
